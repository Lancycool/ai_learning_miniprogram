# 可观测性说明

当前项目提供两层可观测性能力：统一结构化日志和 Prometheus 指标。两层能力都不改变现有业务接口。

## 统一日志

后端启动时会安装 JSON 日志格式。每条请求日志会包含以下字段：

```json
{
  "timestamp": "2026-10-09T12:00:00+0000",
  "level": "INFO",
  "logger": "app.main",
  "message": "http_request_finished",
  "request_id": "req_example",
  "task_id": "qtask_example",
  "method": "GET",
  "path": "/api/v1/quizzes/generation-tasks/{id}",
  "status_code": 200,
  "duration_ms": 23.4
}
```

客户端可以通过 `X-Request-ID` 传入请求编号。后端只接受 8 至 128 个安全字符。请求编号不符合格式时，后端会重新生成编号。后端会把最终编号写入响应头 `X-Request-ID`。

后台出题任务会把 `task_id` 放入同一条日志上下文。任务日志、模型调用日志、联网搜索日志和异常日志可以通过 `request_id` 或 `task_id` 关联。

日志不保存 API Key、完整私有文档、完整 Prompt 或完整上游异常正文。部署者可以通过 `OBSERVABILITY_LOG_LEVEL` 调整日志等级，默认值为 `INFO`。

## Prometheus 指标

后端提供：

```text
GET /metrics
```

接口返回 Prometheus 文本格式。Prometheus 可以使用下面的配置抓取本机服务：

```yaml
scrape_configs:
  - job_name: bamboo-quiz-backend
    metrics_path: /metrics
    static_configs:
      - targets: ["127.0.0.1:8000"]
```

系统当前提供以下指标：

| 指标 | 含义 |
| --- | --- |
| `http_requests_total` | HTTP 请求数量，按方法、规范化路径和状态码统计 |
| `http_request_duration_seconds` | HTTP 请求耗时 |
| `quiz_task_created_total` | 出题任务提交数量，按普通或私有范围统计 |
| `quiz_task_finished_total` | 出题任务完成数量，按范围和结果统计 |
| `quiz_task_queue_wait_seconds` | 出题任务在队列中的等待时间 |
| `quiz_task_duration_seconds` | 出题任务执行时间 |
| `knowledge_retrieval_total` | 私有知识库出题次数，按成功或失败统计 |
| `knowledge_retrieval_duration_seconds` | 私有知识库出题耗时 |
| `web_search_total` | 联网搜索次数，按 success、fallback 或 disabled 统计 |
| `web_search_duration_seconds` | 联网搜索耗时 |

HTTP 指标会把任务编号替换成 `{id}`，这样可以避免每个任务产生新的指标标签。系统不会把用户输入、文档标题或搜索查询放入 Prometheus 标签。

## 建议告警

部署者可以先设置以下告警：

```text
任务失败率连续 5 分钟超过 10%
任务队列等待时间 P95 超过 30 秒
私有检索失败率连续 5 分钟超过 5%
联网搜索 fallback 比例连续 5 分钟超过 30%
HTTP 5xx 比例连续 5 分钟超过 2%
```

告警触发后，维护者可以先使用 `task_id` 查询维护者页面中的知识库追踪，再根据 `request_id` 查询应用日志。

## 本地检查

启动后端后可以执行：

```powershell
curl http://127.0.0.1:8000/metrics
```

测试可以执行：

```powershell
uv run --directory backend python -m pytest tests/test_observability.py
```

当前指标注册器使用进程内存保存数据。后端重启后，计数器会重新开始。多进程部署时，每个进程需要单独抓取，或者后续改用 Prometheus 客户端和多进程聚合目录。
