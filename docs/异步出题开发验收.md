# 异步出题开发验收

开发者在 2026 年 10 月 3 日将小程序首页切换为数据库任务与轮询。系统保存任务后返回 202，后台工作协程执行原出题流程，前端每 5 秒查询任务。用户离开页面后，已提交任务继续执行，前端会在用户回来时恢复查询。

后端最终回归共有 115 项测试通过，覆盖率为 91.59%。其中任务测试共有 15 项。前端任务测试、联网状态测试、类型检查和微信小程序构建均通过。

## 后端验证

开发者使用专用 MySQL 测试库验证创建请求立即返回、queued 到 running 再到 succeeded 的状态变化，以及成功后的题库和学习记录。重复提交使用原任务和学习记录，两个工作协程只能领取同一任务一次。应用 lifespan 测试确认创建连接关闭后，后台仍能生成，后续连接可以查询结果。

开发者测试了搜索成功、搜索失败回退和关闭搜索。任务查询不会提前返回答案、解释或参考来源。其他用户查询任务时，系统返回 404。

开发者测试了模型失败、任务超时、保存失败、排队超时、执行期限过后到达的结果，以及工作协程关闭。系统失败时记录受控原因，保存失败会回滚题库、题目和学习记录。后端重启后可以领取原排队任务，超出执行期限的任务会被记为中断。日志故障不会停止工作协程的数据库错误恢复。

任务迁移测试检查升级、降级、重复升级和已有用户保留。本地数据库已升级到 `20261003_0003`。开发者还临时启动了 uvicorn，健康检查和工作协程启动均通过。开发者已关闭临时服务。

## 前端验证

前端请求测试检查 POST 后的连续 GET、五秒间隔、请求不重叠、完成后返回题库，以及任务完成前的状态回调。测试还检查暂停时清理定时器、账号之间隔离任务、返回后恢复、创建响应丢失后使用原请求编号重试、查询错误恢复、连续三次查询失败后保留任务，以及最终失败后允许重新提交。

首页测试确认用户回来后恢复原主题与搜索开关，任务完成前不会跳转，任务成功后会创建页面会话并进入闯关页面。用户离开后，页面会忽略迟到结果，不会自动跳转。

前端联网状态与参考资料隐藏测试、类型检查和微信小程序构建均通过。开发者尚未进行微信真机操作验收。

## 复现命令

开发者可以在项目根目录执行数据库升级和启动命令。

```powershell
uv run --directory backend alembic upgrade head
uv run --directory backend uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

开发者可以在 backend 目录执行以下测试。测试会重建专用测试库的表。

```powershell
.venv/Scripts/python.exe -X utf8 -m pytest --cov=app --cov-report=term --cov-fail-under=90
```

开发者可以在 frontend 目录执行以下检查。

```powershell
pnpm test:web-search
pnpm test:quiz-tasks
pnpm typecheck
pnpm build:weapp
```

系统默认每个后端进程启动两个工作协程。团队增加进程数量时，实际模型和搜索并发也会增加。系统异常退出后不会自动重新调用已领取任务，用户需要在任务被记为中断后重新生成。系统保留旧同步接口供旧客户端与脚本使用，当前小程序使用新任务接口。
