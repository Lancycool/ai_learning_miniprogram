# knowledge-based-quiz-generation Specification

## Purpose

系统让用户根据自己选择的私有文档与章节生成学习题目。系统允许用户明确开启公开网络补充，并保存实际使用的资料依据。系统在资料不足或检索故障时给出明确结果，避免把模型自身的猜测当成用户私有知识。

## Requirements

### Requirement: 系统按照用户选择的资料范围出题
系统 MUST 校验知识库、文档与章节归属和版本，并且只检索用户选择的已就绪内容。系统 MUST 在提交任务时保存资料范围，在任务执行和结果发布前再次检查它是否仍有效。系统 MUST 不因章节为空、编号错误或版本变化而静默扩大范围。

#### Scenario: 用户只选择一个章节
- **WHEN** 用户选择当前知识库的一篇文档中的一个章节并生成题目
- **THEN** 系统只使用这个章节中的私有资料作为依据
- **AND** 系统不引用其他用户或未选章节的片段

#### Scenario: 用户提交后删除所选文档
- **WHEN** 用户提交生成任务后，所选文档被删除
- **THEN** 系统停止使用该资料并返回受控的资料失效结果，不发布迟到题库

### Requirement: 私有出题默认禁止联网
系统 MUST 在私有出题请求未明确允许联网时关闭联网工具，即使全局联网开关已经打开。用户明确开启且后端允许时，系统 SHALL 允许 Agent 选择知识库检索或公开网络补充。后端关闭决定 MUST 优先于用户请求。

#### Scenario: 私有请求省略联网字段
- **WHEN** 用户选择私有资料，且请求未明确设置允许联网
- **THEN** 系统不调用搜索服务，并只依据私有资料出题

#### Scenario: 用户允许公开资料补充
- **WHEN** 用户明确开启联网，且后端允许联网
- **THEN** Agent 可以根据学习目标选择受限的检索工具
- **AND** 系统保存实际使用的私有与网络来源

### Requirement: 网络补充不泄露私有检索内容
系统 MUST 不把私有文档正文、检索片段、原题或答案拼入公开搜索查询。系统 MUST 在联网前使用用户单独确认的公开检索主题，并拒绝明显敏感的查询。系统 MUST 不使用公开资料替换企业私有制度或流程；出现冲突时，系统 MUST 使用私有资料并提示来源差异。

#### Scenario: 私有片段包含内部服务地址
- **WHEN** Agent 检索到含内部地址的资料后尝试使用网络工具
- **THEN** 系统只发送此前确认的公开主题，不发送内部地址或该片段

#### Scenario: 用户没有提供有效公开主题
- **WHEN** 用户打开联网，但没有确认可以公开发送的主题
- **THEN** 系统要求用户填写或确认公开主题，不从私有正文自动提取查询

### Requirement: 系统限制 Agent 的权限与执行预算
系统 MUST 限制 Agent 的模型调用数、工具调用数和总执行时间。系统 MUST 不允许模型修改用户身份、资料范围、服务地址、密钥或联网权限。系统 MUST 把文档与网页中的指令当作资料内容，不执行其中的工具配置要求。

#### Scenario: 文档要求读取其他用户资料
- **WHEN** 用户选择的文档包含要求扩大权限或读取其他用户资料的指令
- **THEN** 系统仍只检索服务端确认的当前用户资料范围

#### Scenario: Agent 反复调用工具
- **WHEN** Agent 达到工具次数、模型次数或时间限制
- **THEN** 系统停止进一步调用，并按照已取得的证据给出合格结果或受控失败

### Requirement: 有效资料不足时系统停止私有出题
系统 MUST 在没有相关依据、依据不足以支持题量、检索失败或证据检查不通过时提示补充材料或稍后重试。系统 MUST 不转入普通模型记忆出题，不伪造成功或引用。网络补充失败但私有证据充足时，系统 SHALL 继续使用私有证据，并说明本次未使用网络补充。

#### Scenario: 所选章节只有无关资料
- **WHEN** 检索结果无法支持用户学习目标
- **THEN** 任务返回资料不足提示，并且不创建可答题的题库

#### Scenario: 网络超时但私有证据充足
- **WHEN** 用户允许联网，但搜索超时，私有资料可以支持完整题库
- **THEN** 系统使用私有资料完成出题，记录网络补充失败，并保留真实私有来源

### Requirement: 生成题目必须有可检查的资料依据
系统 MUST 为每道生成题目保存实际检索到的依据标识与必要摘录，并校验标识、摘录与题目答案的支持关系。系统 MUST 保留现有普通生成题库的五题组成规则。系统 MUST 不把结构检查或模型校验通过描述为百分之百正确。

#### Scenario: 模型返回未检索到的引用
- **WHEN** 模型引用不存在的文档、片段或网页标识
- **THEN** 系统拒绝该结果，不保存伪造的引用

#### Scenario: 模型答案与提供的制度冲突
- **WHEN** 题目答案不符合本次依据中的私有制度
- **THEN** 系统拒绝或在受限次数内重新生成，仍不合格时返回失败

### Requirement: 用户通过异步任务进入现有闯关流程
系统 MUST 在保存知识库出题任务后返回任务状态，并在后台处理完成后保存题库与初始学习记录。前端 MUST 每五秒查询任务，成功后才进入闯关页面。系统 MUST 防止重复请求创建多个题库，并且不能在用户离开页面后因迟到响应自动跳转。

#### Scenario: 生成尚未完成
- **WHEN** 用户查询正在运行的知识库出题任务
- **THEN** 系统返回实际状态，不返回题库结果或未作答答案

#### Scenario: 用户回到页面恢复任务
- **WHEN** 用户重新进入页面且之前的任务已成功
- **THEN** 页面取得原题库与学习记录，并允许用户进入闯关

### Requirement: 引用展示遵守学习记录权限
系统 MUST 在当前学习记录完成前隐藏可泄露答案的引用摘录和来源链接。系统 MUST 在完成后展示真实来源、文档版本与章节。用户重做题库时，系统 MUST 再次隐藏引用内容。系统 MUST 不把私人引用放入公开分享内容。

#### Scenario: 用户完成闯关查看依据
- **WHEN** 当前用户完成学习记录并查看报告或历史详情
- **THEN** 系统显示生成时保存的文档章节与引用快照

#### Scenario: 用户再次练习旧题库
- **WHEN** 用户为同一题库创建未完成的新学习记录
- **THEN** 系统保留原依据，但再次隐藏可泄露答案的引用内容

### Requirement: 普通主题出题保持原有行为
系统 MUST 在用户未选择私有资料时继续使用现有普通出题与联网开关规则。搜索失败时系统 MUST 继续使用原 Prompt，旧题库 MUST 可以继续读取。新资料字段缺省时，系统 MUST 不改变现有题型、任务、答案、XP、历史和报告含义。

#### Scenario: 旧客户端提交普通出题请求
- **WHEN** 请求只有原有主题、题量、难度与联网字段
- **THEN** 系统执行原有普通生成路径，并返回兼容的任务和题库结果
