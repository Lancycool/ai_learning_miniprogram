# Proposal

## Why

用户需要学习企业制度、培训材料和自己的考试题库。现有模型知识与 Tavily 搜索无法覆盖这些私有资料。项目需要提供用户私有知识库、按章节学习和原题导入，并继续使用现有异步任务与闯关流程。

## What Changes

- 系统新增个人知识库管理。用户可以上传 PDF、DOCX、Markdown、TXT，也可以保存一段文字。单个文件最多为 30 MB。
- 系统通过 LangChain 文档解析器提取文字和章节，再使用北京地域的百炼 `text-embedding-v4` 建立 Chroma 本机持久化索引。系统读取用户已有的 `BAILIAN_API_MODEL`、`BAILIAN_API_KEY`、`BAILIAN_API_BASE_URL`。
- 用户可以选择文档和章节。系统提供章节预览与确认，不提供页码选择。系统通过数据库任务处理解析、索引和题库导入。前端每五秒查询状态，用户返回页面后可以继续查看。
- 系统新增知识库出题路径。LangChain Agent 在当前用户允许的资料范围内检索。私有出题默认关闭联网；用户明确允许后，Agent 才能调用现有 Tavily 搜索。资料不足时系统提示补充材料，不改用模型记忆。
- 系统新增单选、多选、判断原题的完整导入。系统保留原题文字、原选项与原答案，并提供可编辑的预览。用户需要补齐缺失答案和确认存疑内容，再确认入库。AI 不自动替原题编答案。用户可以按章节练习，每组最多五题，系统不强制题型比例。
- 系统保存本次检索与原题引用快照。系统在当前学习记录完成前隐藏引用内容。用户删除资料后，系统停止检索并清理原文件和索引；已经进入学习记录的题目、引用快照和成绩继续保留。
- 我们为全部新增后端功能执行先失败、后实现的 TDD。我们补充前端测试、迁移检查和现有功能回归。网页、视频、扫描件 OCR、团队共享和新题型进入后续版本。

## Capabilities

### New Capabilities

- `private-knowledge-bases`: 系统管理用户知识库、私有文件、文字资料、文档处理任务、章节和持久化索引。
- `knowledge-based-quiz-generation`: 系统基于允许的文档与章节执行 Agentic RAG、受控联网、依据检查和异步出题。
- `original-question-import`: 系统提取、审核、确认与保存原题，并支持按章节分组练习和历史引用。

### Modified Capabilities

无。当前 `openspec/specs/` 没有主规范。已有联网变更仍在独立目录中；本次保留它描述的普通联网出题与失败回退行为。新增私有路径不覆盖普通出题的规则。

## Impact

- 后端：我们新增知识库、文档版本、章节、处理任务、原题草稿与题库记录。我们增加 Alembic 迁移和 SQL 快照，并为现有题目增加兼容原题长文本与引用的存储能力。我们扩展任务请求和工作协程的分发，保留旧请求含义。
- 接口：我们新增受登录保护的知识库、上传、章节确认、原题审核和练习接口。我们扩展现有异步出题请求的资料范围，新增字段缺省时仍走原有流程。
- 前端：我们替换首页的文档占位入口，增加知识库与原题管理页面，并扩展任务恢复、章节选择和完成后的引用展示。我们保留现有答题、XP、错题、历史和报告的业务规则。
- 依赖与部署：我们增加 `langchain-community`、`langchain-chroma`、Chroma、指定解析器的必要依赖和章节结构读取依赖。我们保持当前 LangChain 与 DeepSeek 核心版本，并使用现有 MySQL 与本机文件目录。我们只在新功能启用后加载其依赖和服务。
- 文档：我们更新 `docs/需求分析文档.md`、`docs/方案设计文档.md`、扩展输入原型、配置示例和验收记录。真实密钥、私有文件、索引与测试产物不进入 Git。
