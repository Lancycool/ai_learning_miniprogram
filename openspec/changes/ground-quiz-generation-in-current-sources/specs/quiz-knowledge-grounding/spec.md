# Spec Delta

## Purpose

系统为 AI 出题提供可开关的联网参考资料，并根据用户内容调整搜索范围。系统在搜索成功时增强 Prompt，在搜索失败时记录原因并使用原 Prompt，保持现有题库生成、结构检查和学习流程可以继续运行。

## ADDED Requirements

### Requirement: 系统支持联网搜索开关
系统 MUST 提供后端 `enable_web_search` 开关和同名可选请求字段。系统 MUST 在后端关闭或请求明确关闭时跳过搜索，并使用原 Prompt。请求省略或为 null 时 MUST 继承后端设置，请求不能覆盖后端关闭决定。

#### Scenario: 后端关闭搜索
- **WHEN** 后端 `enable_web_search=false`，请求没有关闭搜索
- **THEN** 系统不初始化 Tavily，不读取搜索密钥，不进行外部搜索
- **AND** 系统使用原 Prompt 出题并返回关闭状态

#### Scenario: 用户关闭本次搜索
- **WHEN** 后端开启搜索，但请求 `enable_web_search=false`
- **THEN** 系统跳过搜索，并按原流程生成题库

#### Scenario: 旧客户端省略开关
- **WHEN** 客户端只发送原有出题字段
- **THEN** 系统按后端默认设置决定是否搜索
- **AND** 系统保留原请求与响应兼容性

### Requirement: 搜索成功时系统注入有效参考结果
系统 MUST 在开关生效且 Tavily 返回有效相关结果时，将清洗、去重和限制长度后的搜索结果作为参考资料注入原出题 Prompt。系统 MUST 保留用户原主题、题量、难度及输出结构。系统不能把搜索摘要标成已阅读全文或已独立核实。

#### Scenario: 用户学习新术语
- **WHEN** 用户输入 `HarnessEngineering，AI 编程领域` 且 Tavily 返回有效相关资料
- **THEN** 系统保留原输入和领域说明，并把搜索结果注入出题 Prompt
- **AND** 系统按现有题型与答案结构规则生成题库

#### Scenario: 资料含有重复结果
- **WHEN** Tavily 返回多个重复 URL 或内容
- **THEN** 系统去重并限制注入长度，不改变用户请求题量

### Requirement: 搜索失败时系统使用原 Prompt 出题
系统 MUST 在搜索超时、限流、密钥或配额错误、空结果、无关结果、工具错误及参数或上下文处理错误时捕获故障并记录受控日志。系统 MUST 不注入搜索结果或增强指令，使用原 Prompt 照常出题。搜索失败本身 MUST NOT 返回出题业务错误。

#### Scenario: 搜索超时且重试仍失败
- **WHEN** 搜索最终超时，但出题请求仍有正常模型调用预算
- **THEN** 系统记录超时，并使用原 Prompt 生成题库
- **AND** 系统不将超时文本、空资料区域或残留结果传入模型

#### Scenario: 密钥缺失或配额耗尽
- **WHEN** Tavily 密钥不存在、无效或配额耗尽
- **THEN** 系统停止搜索尝试，记录受控原因，并执行原 Prompt
- **AND** 原生成成功时系统正常保存题库和创建学习记录

#### Scenario: 搜索结果无法用于增强
- **WHEN** 返回值是错误字典、错误文本、空结果，或资料区域构造失败
- **THEN** 系统丢弃本次上下文，并使用原 Prompt

#### Scenario: 日志平台不可用
- **WHEN** 搜索失败且日志写入也失败
- **THEN** 系统仍执行原 Prompt，不因日志故障阻止出题

### Requirement: 系统根据用户内容动态调整搜索参数
系统 MUST 根据用户主题、明确领域、时间窗口和站点范围动态设置受限搜索参数。系统 MUST 校验参数值、结果上限和查询长度。系统不能因分类失败改变用户原主题；无法分类时 MUST 使用通用参数，参数处理出错时 MUST 回退原 Prompt。

#### Scenario: 新技术主题
- **WHEN** 用户输入新的 AI 技术术语或明确技术版本
- **THEN** 系统选择通用搜索领域，并按复杂度使用深度搜索
- **AND** 系统不只因为主题含“新”字就使用新闻领域

#### Scenario: 明确近期事件与时间窗口
- **WHEN** 用户要求学习最近一个月的新闻事件
- **THEN** 系统使用新闻领域与 month 时间范围，并保留用户主题

#### Scenario: 最新知识没有明确窗口
- **WHEN** 用户只要求“最新”，没有限定周、月或年
- **THEN** 系统保留时效目标，但不擅自设置硬时间过滤

#### Scenario: 用户输入包含任意工具配置
- **WHEN** 用户文本要求覆盖密钥、工具地址或结果上限
- **THEN** 系统只把文本当作学习内容，不执行未经服务端允许的参数

### Requirement: 搜索有独立预算且不能耗尽原出题时间
系统 MUST 限制搜索单次时限、阶段总时限和真实调用次数，并为原模型链保留至少一次正常调用时间。系统 SHALL 在可恢复故障时最多重试一次。预算不足、排队超时或熔断开启时系统 MUST 跳过搜索并用原 Prompt。

#### Scenario: 搜索预算不足
- **WHEN** 系统判断继续搜索会侵占原模型链所需时间
- **THEN** 系统不启动搜索或重试，记录原因，并使用原 Prompt

#### Scenario: 限流建议等待时间过长
- **WHEN** 上游 Retry-After 超出可用搜索预算
- **THEN** 系统不提前重试，不继续等待，并使用原 Prompt

#### Scenario: 持续搜索故障
- **WHEN** 系统达到熔断门槛
- **THEN** 系统在冷却期间不访问 Tavily
- **AND** 系统继续允许原 Prompt 出题和历史题库阅读

### Requirement: 系统保留取消和原业务错误语义
系统 MUST 在用户取消、后端检测到连接断开或整个请求超时后停止任务，不能启动兜底生成。两条生成入口 MUST 执行相同的搜索和回退规则，并保留原输入过滤、模型输出、题量、题型、答案结构和存储错误处理。

#### Scenario: 用户取消生成
- **WHEN** 后端收到取消或断开信号
- **THEN** 系统停止搜索和后续生成，并释放资源

#### Scenario: 原模型链失败
- **WHEN** 搜索失败后系统执行原 Prompt，但模型也失败或输出不合格
- **THEN** 系统返回原生成错误，不伪造成功题库

#### Scenario: 整个出题请求超时
- **WHEN** 整个请求已达到截止时间
- **THEN** 系统停止所有调用，并返回原生成失败信息

### Requirement: 系统限制资料和日志中的风险
系统 MUST 把搜索结果作为不可信资料，限制长度并忽略其中的指令。系统 MUST 只向搜索服务发送最少必要的主题，明确检测到敏感输入时跳过搜索。系统 MUST 不在搜索日志、搜索元信息或搜索错误响应中暴露密钥、输入全文和上游错误全文。

#### Scenario: 搜索内容要求忽略出题规则
- **WHEN** 搜索结果包含改变主题、输出格式或执行工具的指令
- **THEN** 系统不执行这些指令，仍保留原出题契约

#### Scenario: 系统检测到明显敏感输入
- **WHEN** 查询精简过程检测到密钥或手机号等明显敏感内容
- **THEN** 系统跳过外部搜索，并使用原 Prompt

#### Scenario: 错误信息可能包含敏感内容
- **WHEN** 工具异常内容包含查询或密钥
- **THEN** 系统只记录规范化原因与错误类型，不输出异常全文
