# Spec Delta

## Purpose

系统记录题库生成时是否开启搜索、是否实际使用搜索结果以及最终 Prompt 路径，让用户可以区分联网参考与模型已有知识。系统保存实际参考来源和降级原因，并避免把搜索成功或结构检查通过误称为事实已经核实。

## ADDED Requirements

### Requirement: 系统记录实际搜索与 Prompt 路径
系统 MUST 保存并返回可选搜索元信息，包含 requested、有效开关、status、context_used、实际参数、尝试次数、受控降级原因和 Prompt 版本。status MUST 区分 success、fallback 和 disabled。系统不能把搜索尝试记录为资料已注入。

#### Scenario: 正常联网增强
- **WHEN** 系统成功取得并实际注入搜索结果
- **THEN** 系统返回 success 与 context_used=true，并记录增强 Prompt 版本及实际来源

#### Scenario: 搜索失败后原链成功
- **WHEN** 搜索失败，但原 Prompt 生成合格题库
- **THEN** 系统返回 fallback 与 context_used=false，并记录原 Prompt 版本及受控原因
- **AND** 系统的参考来源列表为空，题库仍属于成功生成

#### Scenario: 用户或后端关闭搜索
- **WHEN** 有效搜索开关为 false
- **THEN** 系统返回 disabled、context_used=false 和尝试次数 0

### Requirement: 系统如实展示参考资料范围
系统 SHALL 展示本次联网或回退状态，并在当前学习记录完成后展示实际注入的参考资料标题与链接。系统 MUST 对未知日期保留未知值，不能伪造来源，也不能声称每道题已经核实或逐题具备依据。

#### Scenario: 用户查看联网参考
- **WHEN** 用户完成当前学习记录后查看联网增强题库的复盘或历史详情
- **THEN** 系统可以展示实际注入的参考标题和来源链接
- **AND** 系统说明资料仅作为本次出题参考

#### Scenario: 用户查看回退题库
- **WHEN** 用户查看搜索失败后生成的题库
- **THEN** 系统显示“系统本次未使用联网资料，题目由模型已有知识生成”
- **AND** 系统不显示伪造来源或联网核实标记

#### Scenario: 用户尚未完成整套题库
- **WHEN** 登录用户尚未完成当前学习记录，即使用户已经答过部分题目
- **THEN** 系统只展示搜索状态，不暴露可能透露后续答案的参考内容和来源链接

#### Scenario: 用户重做题库
- **WHEN** 用户为同一题库创建新的学习记录，且新记录尚未完成
- **THEN** 系统再次隐藏参考内容与链接，保留原搜索状态

### Requirement: 历史记录保存当时的搜索状态
系统 MUST 保存题库生成时的搜索元信息与有限参考上下文，并在续学、重做和历史详情中保留原记录。系统 MUST 遵守现有用户归属限制，不能因搜索服务恢复或网页更新而改写原题库答案。

#### Scenario: Tavily 后续恢复
- **WHEN** 用户打开此前通过原 Prompt 回退生成的题库
- **THEN** 系统保留当时 fallback 状态，不把记录改成联网成功

#### Scenario: 来源网页已经更新
- **WHEN** 用户重看已有联网增强题库
- **THEN** 系统保留原参考记录和原答案，不自动重新搜索或替换题目

#### Scenario: 用户访问其他用户题库
- **WHEN** 用户读取不属于自己的题库搜索元信息
- **THEN** 系统按现有归属规则拒绝访问

### Requirement: 系统兼容没有搜索元信息的旧题库
系统 MUST 将旧题库的新增元信息处理为可空值，并保留原答题、复盘和历史阅读能力。系统不能补造搜索记录或把旧题库标记为本次已核实。

#### Scenario: 用户打开旧题库
- **WHEN** 旧题库没有搜索元信息
- **THEN** 系统显示“历史题库未记录搜索状态”，并允许用户正常答题
